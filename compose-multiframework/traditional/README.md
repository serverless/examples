# Traditional Service (compose-multiframework)

This directory contains the "traditional" Serverless Framework service used by the
[`compose-multiframework`](../README.md) example. It is one of three sub-stacks
(alongside `../cloudformation` and `../sam`) that Serverless Compose deploys and
orchestrates together.

This service is not deployed on its own. See the
[compose-multiframework README](../README.md) for the full example description and
usage instructions (`serverless deploy` / `serverless remove` from the example root).
